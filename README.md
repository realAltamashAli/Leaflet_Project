# Developing Data Products: Interactive Mapping with Leaflet

This repository contains a web page created using R Markdown and the Leaflet package. This project was completed as part of the **Developing Data Products** course from Johns Hopkins University on Coursera.

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-nd/4.0/)

## Project Overview
The objective of this assignment was to create a reproducible, web-hosted document that features:
1.  A date that is current (less than two months old).
2.  An interactive map created with the Leaflet R package.

## Interactive Map
You can view the live interactive map here:
**[https://realAltamashAli.github.io/Leaflet_Project/](https://realAltamashAli.github.io/Leaflet_Project/)**

## Repository Contents
* **index.html**: The final rendered web page (renamed from `Leaflet_Project.html` to enable GitHub Pages).
* **Leaflet_Project.Rmd**: The original R Markdown source code used to generate the map.
* **README.md**: Documentation for this repository.

## Tools Used
* **RStudio**: For data processing and R Markdown authoring.
* **Leaflet**: For the interactive mapping JavaScript library interface.
* **GitHub Pages**: For hosting the final HTML product.

## Data Source
The coordinates used in this project point to the **Eiffel Tower** (48.8584° N, 2.2945° E), a global landmark located in Paris, France.
